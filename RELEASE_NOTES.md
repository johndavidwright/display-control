# DisplayControl 0.3.0

- Added an Updates section with Check for Updates, automatic checks, and optional automatic download and installation.
- Updates use Sparkle, with signed archives and a signed update feed hosted on GitHub Releases.
- Preserved the caret animations and the fix for flashing above the title during collapse.
- Includes the XENEON EDGE RGB readback correction and the DDC verification, persistence, and reconnect improvements from 0.2.5.

Requires Apple Silicon and macOS 13 or later. The app is ad-hoc signed and is not notarized.

Version 0.2.5 does not have an updater. Install this version manually once; subsequent releases can be installed from the app's Updates section.
